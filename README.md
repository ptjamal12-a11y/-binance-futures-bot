# Binance Futures Signal Scanner

بوت تحليلي يفحص أسواق Binance USDⓈ-M Futures ويصنّف فرص LONG وSHORT اعتمادًا على:

- EMA 7 / 25 / 99
- RSI 14
- MACD
- حجم التداول
- ATR لتقدير وقف الخسارة والأهداف
- سيولة السوق وحجم التداول خلال 24 ساعة

## مهم

هذا المشروع **لا يفتح صفقات ولا يستخدم مفاتيح حساب Binance**.  
هو ماسح إشارات للتحليل والتجربة فقط. النتائج ليست ضمانًا للربح، والرافعة المالية قد تسبب تصفية سريعة.

## التشغيل على Render

1. ارفع جميع الملفات إلى مستودع GitHub.
2. افتح Render.
3. اختر **New > Blueprint**.
4. اربط مستودع GitHub.
5. سيقرأ Render ملف `render.yaml` وينشئ الخدمة.
6. بعد اكتمال النشر افتح رابط الخدمة.

## الروابط

- `/` معلومات البوت
- `/health` فحص التشغيل
- `/scan` فحص يدوي
- `/scan?notify=true` فحص وإرسال النتائج إلى تيليجرام عند ربطه
- `/signals` آخر الإشارات
- `/signals?limit=5` أفضل خمس إشارات

## ربط تيليجرام لاحقًا

في Render افتح **Environment** وأضف:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

ثم أعد تشغيل الخدمة.

## إعدادات قابلة للتعديل

- `INTERVAL=5m`
- `SCAN_EVERY_SECONDS=300`
- `MAX_SYMBOLS=80`
- `MIN_QUOTE_VOLUME=25000000`
- `MIN_SCORE_TO_NOTIFY=75`

## ملاحظة عن Render Free

الخدمة المجانية قد تدخل وضع السكون، لذلك لا يُعتمد عليها لإشعارات تداول لحظية دائمة. هي مناسبة للتجربة الأولى، وبعد نجاح الاستراتيجية يمكن نقلها إلى خدمة مدفوعة أو خادم دائم.
