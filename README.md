# Binance Futures Scalping Scanner Pro

نسخة شاملة لفحص عقود Binance USDⓈ-M تلقائيًا واختيار أفضل 3 فرص سكالبينغ LONG أو SHORT.

## ما الذي يفعله؟

- فحص تلقائي كل دقيقة
- فريم دخول 3 دقائق واتجاه 15 دقيقة
- EMA 7 / 25 / 99
- RSI وMACD وATR والفوليوم
- Funding Rate
- تغير Open Interest
- فلترة السيولة
- أفضل 3 فرص فقط
- دخول مرجعي ووقف وهدفان
- منع تكرار الإشارة لمدة 45 دقيقة
- إرسال إلى تيليجرام
- لوحة سهلة على `/dashboard`

## مهم

البوت لا يفتح صفقات ولا يحتاج API Key من حساب Binance. هو للتحليل فقط.

## التحديث من الآيفون

1. فك ضغط الملف.
2. في GitHub افتح المستودع.
3. Add file ثم Upload files.
4. اختر جميع الملفات الموجودة داخل المجلد.
5. اختر Commit directly to main.
6. اضغط Commit changes.
7. Render سيعيد النشر تلقائيًا بسبب ربط Blueprint.

## تيليجرام

في Render أضف القيم السرية:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`

لا تضعها داخل GitHub لأن المستودع عام.

## الروابط

- `/dashboard` لوحة النتائج
- `/scan` فحص يدوي
- `/signals` أفضل الفرص
- `/history` سجل الإشارات
- `/health` حالة الخدمة

## تنبيه Render Free

الخدمة المجانية قد تدخل وضع السكون، ولذلك قد لا تكون مناسبة لإشعارات لحظية مضمونة على مدار الساعة. للتجربة ممتازة، وللتشغيل الدائم استخدم خطة مدفوعة أو خادمًا دائمًا.


## مراجعة الاستقرار
تم تثبيت Python 3.11.11 وتقليل عدد الأسواق والخيوط لتناسب Render Free، وإضافة فحص صياغة أثناء البناء ومعالجة فشل Open Interest دون إيقاف التحليل.
